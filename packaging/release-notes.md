## Download

- **Windows 10 / 11 (64-bit):** download the `windows-x64.zip` file below, unzip it and double-click `veloforge.exe`. Windows may warn that it "protected your PC" because the program is new and unsigned: click **More info**, then **Run anyway**. `README-Windows.txt` in the zip explains the rest.
- **Linux:** build and install it from source with `./install.sh`, as the [README](https://github.com/hmaltawil/veloforge-1#install) explains.

To try it without a trainer, start it with `--demo --workout`.

**The Windows version is new.** The app, the 3D world, workouts, sounds and the phone remote work, but connecting to trainers and heart rate straps over Bluetooth has not yet been tested on Windows. If you try it, please [open an issue](https://github.com/hmaltawil/veloforge-1/issues) with what happened and the log from **Devices → Copy log**.
